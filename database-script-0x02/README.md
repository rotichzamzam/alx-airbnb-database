# Airbnb Database – Sample Data Population

##  Objective
This directory contains SQL scripts for inserting **sample data** into the Airbnb database to simulate real-world usage.

##  Files
- **seed.sql** – Populates tables (`User`, `Property`, `Booking`, `Payment`, `Review`, `Message`) with realistic sample data.
- **README.md** – Documentation and usage instructions.

##  Tables Populated
- **User:** Inserts 3 users (guest, host, admin)
- **Property:** 2 listings owned by the host
- **Booking:** 2 bookings linked to users and properties
- **Payment:** 1 successful payment
- **Review:** 1 review left by a guest
- **Message:** 2 exchanged messages between users
